# Chat conversation stdio boundary

Tool names must be strings before catalog membership testing. Invalid list,
object, null, and numeric names return JSON-RPC invalid parameters without
identity resolution or dispatch; the stream remains usable for later requests.

A configured conversation resolver disables fixed-principal events consistently:
protocol advertising, event operations, and background stdio pumping. The fixed
service entrypoint retains its existing event pump. Conversation-specific event
delivery is not provided by this boundary.
