# Pane Background Face Stock

Set the private `TPROJ_PANE_BG_FACE_STOCK_DIR` environment variable to a local
directory of readable PNG references. When a new female pane image is generated,
the selector chooses a stable project-and-role hash slot among the sorted PNGs
and records its basename and path in the ignored project sidecar
`.local/tproj-pane-bg/<role>.face-reference.json`. Later stock additions do not
reassign a pinned pane.

An explicit `TPROJ_PANE_BG_REFERENCE_IMAGE` still wins. A project
`.local/tproj-pane-bg/prompt.local.json` may name a stock basename with
`face_reference_cc` or `face_reference_cdx`; an invalid name fails the request
instead of silently selecting another face. Existing cached images are not
invalidated or regenerated by enabling the stock directory, and male panes do
not use the stock. If a pinned file disappears, generation fails closed until
the pin is repaired or an explicit stock name is supplied.
